# Hilbert, *The Foundations of Geometry*, in Lean 4

David Hilbert's *The Foundations of Geometry*, in E. J. Townsend's 1902 translation ([Project Gutenberg #17384](https://www.gutenberg.org/ebooks/17384), public domain in the USA), formalized in Lean 4 and mathlib.

Every axiom, theorem and claim of the book is a *unit*. Each unit quotes the text, says how it is read in Lean, and gives the declarations that prove it. Where Hilbert is wrong or imprecise, the unit says so and proves the correct statement.

> **Work in progress.** Every chapter is formalized and builds: 430 units, 28 of them stated but not yet proved (listed in [docs/UNITS.md](docs/UNITS.md)). The documentation is not yet written.

## Status

The unit map, with each unit's status and file, is [docs/UNITS.md](docs/UNITS.md), generated by `scripts/unit_table.py`.

## Layout

```
HilbertFoundations.lean               root: imports every chapter
HilbertFoundations/Basic.lean         the axioms I–V as Lean classes, standalone axiom statements
HilbertFoundations/Order.lean         §§ 2–5: consequences of the axioms of connection and order
HilbertFoundations/Congruence.lean    §§ 6–7: congruence
HilbertFoundations/Analytic.lean      §§ 9, 13: the analytic models
HilbertFoundations/Independence.lean  §§ 10–12: independence and compatibility of the axioms
HilbertFoundations/Pascal.lean        § 14: Pascal's theorem
HilbertFoundations/Proportion.lean    §§ 15–17: algebra of segments, proportion
HilbertFoundations/Areas.lean         §§ 18–21: plane areas
HilbertFoundations/Desargues.lean     § 22: Desargues's theorem
HilbertFoundations/NonDesargues.lean  § 23: a non-Desarguesian plane geometry
HilbertFoundations/DesarguesAlgebra.lean §§ 24–30: the algebra of segments from Desargues's theorem
HilbertFoundations/NonPascal.lean     §§ 31–35: Pascal's theorem and commutativity
HilbertFoundations/Constructions.lean §§ 36–39: constructions with ruler and segment-transferer
HilbertFoundations/Commentary.lean    introduction, conclusion, appendix
HilbertFoundations/*Aux*.lean         helper lemmas, split for build memory
data/foundations.json                 the text, extracted from the Gutenberg LaTeX
docs/UNITS.md                         generated unit map
scripts/                              extraction, skeletons, unit map, axiom audit, checker
```

## Building

Lean v4.36.0 and mathlib v4.36.0 are pinned in `lean-toolchain` and `lakefile.toml`.

```sh
lake exe cache get                       # download prebuilt mathlib
lake build
lake env lean scripts/AxiomsAudit.lean   # only propext, Classical.choice, Quot.sound
python3 scripts/unit_table.py --check
```

On a machine with less than about 32 GB of RAM, build a few modules at a time, or check one file with `python3 scripts/check.py HilbertFoundations/Order.lean`.
