### Lemmas of § 3, each re-derived
- L1 (naturality) and L2 (finSuccEquiv) hold. Ring homomorphisms out of ℚ are unique, and
  `eval₂_finSuccEquiv` was read in Hilbert17/FinSuccEvaluation.lean.
- L3 (density of algebraically independent points) holds. ℚ[σ] lies in the countable subfield
  ℚ(σ). The reals algebraic over a countable domain form a countable set, so its complement is
  dense and meets every ball. `option_iff_transcendental` adds one coordinate, and the reindexing
  is along `finSuccEquiv`. The case d = 0 is trivial.
- L4 holds: f = (Y−b)q, q(b) = f'(b), and q keeps its sign near b. Both sign cases were checked:
  q(b) < 0 gives f(b+ε/2) < 0 < f(b−ε/2), and q(b) > 0 gives the reverse.
- L5 and L6 hold. The two strict inequalities at fixed y₁, y₂ are open conditions in τ, and the IVT
  on ℝ applies to the continuous polynomial y ↦ M(τ; y). A root anywhere in ℝ is enough; it does
  not have to be near β₀ or simple.
- L7 holds (pure algebra; derivative_map and derivative_C_mul).
- L8 holds.
  - char 0 gives a separable extension and hence a primitive element α.
  - μ = minpoly is irreducible, hence separable, so μ'(α) ≠ 0.
  - ℚ(t) = Frac ℚ[t], with ℚ[t] ≅ A_d because t is algebraically independent.
  - integerNormalization gives ι(N) = c•μ with c ≠ 0. Then M(t;α) = b(t)μ(α) = 0 and
    M'(t;α) = b(t)μ'(α) ≠ 0, where b(t) ≠ 0 by injectivity of ev_t.
  - For τ algebraically independent, ev_τ∘σ is injective, so it lifts to λ : F → ℝ. From
    0 = M(τ;β) = b(τ)·(λμ)(β) and b(τ) ≠ 0 we get (λμ)(β) = 0.
  - AdjoinRoot.lift, composed with F[Y]/(μ) ≅ F⟮α⟯ = ⊤ ≅ K, gives K →+* ℝ.
  - Degenerate cases: d = 0 is fine. M(τ;·) ≡ 0 cannot happen, because λμ is monic. The argument
    never needs it anyway.
- L9 holds (closure induction).
- L10 holds.
  - ℚ(s) = K.
  - K is algebraic over ℚ[s]. The case q = 0 in x = r/q is harmless, since then x = 0, and
    inv_iff covers 0⁻¹.
  - A transcendence basis u ⊆ s exists and is finite.
  - K is algebraic over ℚ(u), and K = ℚ(u)(s) with s finite, so [K : ℚ(u)] < ∞.
  - The cases s = ∅ and u = s are covered.
- L11 holds (ℚ → ordered field is strictly monotone, so it preserves signs).
- L12 (E) holds. The two-polynomial system {M = 0, M' ≠ 0} with rational coefficients holds at

  ℝ are real closed. Then L6, L3 and L8(3) finish the proof.
- L13 holds.
  - Artin–Schreier gives an order o with a <_o 0.
  - The real closure j is strictly monotone, so j a < 0, −j a = w·w and w ≠ 0.
  - K₀ = ℚ(j(s) ∪ {w}) ⊆ L is finitely generated, has char 0, and its inclusion into L is a map
    into a real closed field.
  - L12 gives φ, and ψ = φ∘j₀ gives ψ(a) = −φ(w₀)² < 0, where φ(w₀) ≠ 0 by injectivity.
  - The universes work: K : Type, and the closure of S in ℝ is in Type.

   oleans were written by `leanc.py`, not lake: `.lake/build/lib/lean/Hilbert17` holds no
   `.trace` files. Some of them predate the commit of the sources:
   - `OrderingSeparation.olean` was built at 16:25.
   - `FractionSemireal.olean` and `ClearDenominators.olean` were built around 16:25–16:27.
   - Commit b901c85 is from 16:47.

   strictly prove it for the committed text. The mathematics is not affected, because the
   statements quoted in § 2.2 match the current sources. R2 already mentions the timestamps.
   *Fix:* in R2 or the compile order, tell the implementer to recompile the `Hilbert17` modules
   that File 3 imports (or rely on the final `lake build`) before declaring the unit closed.
