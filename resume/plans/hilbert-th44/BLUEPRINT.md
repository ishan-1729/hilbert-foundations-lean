**What `TotNonnegOver R R g` says.** `g ∈ R`, and for every ring homomorphism `σ : R →+* ℂ` all of
whose values are real, `σ g` is a nonnegative real number. (The hypothesis on `σ` reads
"`∀ y : R, (y : ℝ) ∈ R → σ y` is real"; the membership `(y : ℝ) ∈ R` is `y.2`, always true.) Only
one kind of instance is used: for a ring homomorphism `ψ : R →+* ℝ`, the composite
`σ := Complex.ofRealHom.comp ψ` is real-valued, so the hypothesis gives `t ≥ 0` with
`((ψ g : ℝ) : ℂ) = (t : ℂ)`, i.e. `0 ≤ ψ g`. So: **`TotNonnegOver R R g` implies `0 ≤ ψ(g)` for
every ring homomorphism `ψ : R → ℝ`**, and this is all the proof uses.

**What `QSOS R g` asks.** `g = u / v` with `u`, `v` sums of squares of elements of `R`, `v ≠ 0`.
The proof gives the stronger `g = g / 1` with `g` itself a sum of squares of elements of `R`.

## 3. MATHEMATICAL PROOF

### 3.0 Strategy, and how it differs from the route of the original sketch

The route of the original sketch (ordering → real closure → finite sign system with rational coefficients
→ transfer to `ℝ` → persistence of a simple root → algebraically independent parameters →
embedding) is kept. Three simplifications remove almost all the polynomial book-keeping.

* **The sign of `g` is not put into the polynomial system.** If `g <_o 0` in the ordered field
  `(R, o)` and `j : R → L` is a real closed ordered extension, then `-j(g) = w·w` for some
  `w ∈ L`, `w ≠ 0`. Replace `R` by the subfield `K₀ := ℚ(j(S), w)` of `L`, which is again finitely
  generated. Any ring homomorphism `φ : K₀ → ℝ` gives `ψ := φ ∘ j : R → ℝ` with
  `ψ(g) = -φ(w)² < 0`. So everything reduces to the sign-free statement
  **(E): a finitely generated field of characteristic `0` that admits a ring homomorphism into
  some real closed field admits a ring homomorphism into `ℝ`.** The polynomials `G`, `H` of the
  route of the original sketch disappear.
* **No denominator condition `D ≠ 0` in the system.** The only polynomial data are one polynomial
  `M ∈ ℚ[T₁,…,T_d][Y]` (a denominator-cleared minimal polynomial of a primitive element `α` over
  `ℚ(t)`) and its `Y`-derivative; the system transferred to `ℝ` is `M = 0 ∧ ∂M/∂Y ≠ 0` (two
  polynomials, `d + 1` variables). The cleared denominator is automatically nonzero at an
  algebraically independent real point.
* **The persistence step needs no smallness in `Y`.** A real polynomial with a simple root takes
  a strictly negative and a strictly positive value; these two strict inequalities are open
  conditions on the parameters; the intermediate value theorem on all of `ℝ` gives a root. The
  root need not be near `β₀` and need not be simple: any real root of the specialized minimal
  polynomial defines the embedding.

**Notation.** `d ∈ ℕ`, `A_d := ℚ[T₁,…,T_d]` (Lean: `MvPolynomial (Fin d) ℚ`). For a commutative
`ℚ`-algebra `B` and `s ∈ B^d`, `ev_s : A_d → B` is the ring homomorphism `T_i ↦ s_i` (Lean:
`MvPolynomial.eval₂Hom (algebraMap ℚ B) s`). For `M ∈ A_d[Y]` and `y ∈ B`,

  `M(s; y) := (ev_s M)(y) ∈ B`  (Lean: `evalAt s y M := (M.map (ev_s)).eval y`),

where `ev_s M ∈ B[Y]` is `M` with `ev_s` applied to the coefficients. `M'` is the derivative of
`M` with respect to `Y` (Lean: `Polynomial.derivative M`). All rings are commutative with `1`.

### Lemma 1 (naturality of evaluation) — `map_evalAt`
Let `φ : B → C` be a ring homomorphism between commutative `ℚ`-algebras, `s ∈ B^d`, `y ∈ B`,
`M ∈ A_d[Y]`. Then `φ(M(s; y)) = M(φ ∘ s; φ(y))`.

*Proof.* A ring homomorphism commutes with evaluation of a polynomial:
`φ((ev_s M)(y)) = ((φ ∘ ev_s) M)(φ y)` (`Polynomial.hom_eval₂`, after rewriting
`(M.map f).eval y = M.eval₂ f y` with `Polynomial.eval_map`). It remains to see that
`φ ∘ ev_s = ev_{φ∘s}` as ring homomorphisms `A_d → C`. Two ring homomorphisms out of `A_d` are
equal if they agree on the constants and on the variables (`MvPolynomial.ringHom_ext`). On a
variable both give `φ(s_i)`. On a constant `q ∈ ℚ` the first gives `φ(algebraMap ℚ B q)` and the
second `algebraMap ℚ C q`; both are the image of `q` under a ring homomorphism `ℚ → C`, and there
is only one such homomorphism (`simp` proves both goals). ∎

### Lemma 2 (`d + 1` variables) — `evalAt_eq_eval₂`
Let `Φ : ℚ[X₀,…,X_d] ≅ A_d[Y]` be mathlib's `MvPolynomial.finSuccEquiv ℚ d` (`X₀ ↦ Y`,
`X_{i+1} ↦ T_i`). For `y ∈ B`, `s ∈ B^d`, `M ∈ A_d[Y]`:
`M(s; y) = (Φ⁻¹ M)(y, s₁, …, s_d)`, the right side being
`MvPolynomial.eval₂ (algebraMap ℚ B) (Fin.cons y s) (Φ⁻¹ M)`.

*Proof.* `Hilbert17Transfer.eval₂_finSuccEquiv` (§ 2.2) applied to `p := Φ⁻¹ M` says
`((Φ p).map ev_s).eval y = eval₂ (algebraMap ℚ B) (Fin.cons y s) p`; and `Φ(Φ⁻¹ M) = M`. ∎

### Lemma 3 (algebraically independent points are dense in `ℝ^d`) — `exists_algebraicIndependent_near`
For every `d`, every `τ₀ ∈ ℝ^d` and every `δ > 0` there is `τ ∈ ℝ^d` with `dist τ τ₀ < δ`
(sup-metric of `Fin d → ℝ`: `max_i |τ_i − τ₀,i| < δ`) such that `τ₁,…,τ_d` are algebraically
independent over `ℚ`.

*Proof.* Induction on `d`, for all `τ₀`, `δ`.

`d = 0`: take `τ := τ₀` (the only point of `ℝ^0`). `dist τ₀ τ₀ = 0 < δ`. The empty family is
algebraically independent (`algebraicIndependent_empty_type`).

`d → d + 1`: let `c₀ := τ₀(0)` and `σ₀ := Fin.tail τ₀ ∈ ℝ^d`. By induction there is `σ ∈ ℝ^d`,
algebraically independent, with `dist σ σ₀ < δ`. Let `C := ℚ[σ₁,…,σ_d] ⊆ ℝ` be the
sub-`ℚ`-algebra generated by the `σ_i` (Lean: `Algebra.adjoin ℚ (Set.range σ)`).

*`C` is countable.* `C` is contained in the subfield `ℚ(σ)` of `ℝ` generated by the finite set
`{σ_i}` (induction on the construction of an element of `C`, `Algebra.adjoin_induction`:
generators, rational constants, sums, products lie in the subfield). A subfield generated by a set
`s` has cardinality `≤ max(#s, ℵ₀)` (`Subfield.cardinalMk_closure_le_max`), here `≤ ℵ₀` because
`s` is finite. A subset of a countable set is countable.

The set of real numbers algebraic over the countable ring `C` is countable
(`Algebraic.countable`), so its complement is dense in `ℝ` (`Set.Countable.dense_compl`). The
open ball `(c₀ − δ, c₀ + δ)` is open and nonempty, hence contains a number `a` that is not
algebraic over `C`, i.e. transcendental over `C`. By
`AlgebraicIndependent.option_iff_transcendental` (applied to the algebraically independent family
`σ`), the family `(a, σ₁, …, σ_d)` indexed by `Option (Fin d)` (`none ↦ a`, `some i ↦ σ_i`) is
algebraically independent over `ℚ`. Reindexing along the bijection
`finSuccEquiv d : Fin (d+1) ≃ Option (Fin d)` (`0 ↦ none`, `i+1 ↦ some i`) with
`algebraicIndependent_equiv'`, the family `τ := Fin.cons a σ ∈ ℝ^{d+1}` is algebraically
independent. Finally `dist τ τ₀ < δ`: by `dist_pi_lt_iff` (valid since `δ > 0`) this is the
conjunction over the coordinates; coordinate `0` is `|a − c₀| < δ` (membership of the ball),
coordinate `i+1` is `|σ_i − σ₀,i| < δ` (from `dist σ σ₀ < δ` by `dist_pi_lt_iff` again). ∎

(Content of `option_iff_transcendental`, for the reader: if `P(a, σ) = 0` with
`P = ∑_k P_k(T) X₀^k`, then `∑_k P_k(σ) a^k = 0`; all `P_k(σ)` vanish because `a` is transcendental
over `ℚ[σ]`; all `P_k` vanish because `σ` is algebraically independent.)

### Lemma 4 (a simple real root forces both signs) — `exists_neg_pos_of_simple_root`
Let `f ∈ ℝ[Y]`, `b ∈ ℝ`, `f(b) = 0`, `f'(b) ≠ 0`. Then there are `y₁, y₂ ∈ ℝ` with
`f(y₁) < 0 < f(y₂)`.

*Proof.* Since `f(b) = 0`, `f = (Y − b) · q` with `q := f /ₘ (Y − b)`
(`Polynomial.mul_divByMonic_eq_iff_isRoot`). Differentiating, `f' = q + (Y − b) q'`, so
`q(b) = f'(b) ≠ 0`; and `f(y) = (y − b) q(y)` for all `y` (both by `simp` after rewriting `f`).
The set `{y | 0 < q(y) · q(b)}` is open (`q` is continuous: `Polynomial.continuous`) and contains
`b` (`q(b) · q(b) > 0`), so it contains a ball: there is `ε > 0` with `q(y) q(b) > 0` whenever
`|y − b| < ε`. Put `y_± := b ± ε/2`; then `q(y_−) q(b) > 0` and `q(y_+) q(b) > 0`.
* If `q(b) < 0`: then `q(y_±) < 0`, so `f(y_+) = (ε/2) q(y_+) < 0` and
  `f(y_−) = (−ε/2) q(y_−) > 0`; take `y₁ := y_+`, `y₂ := y_−`.
* If `q(b) > 0`: then `q(y_±) > 0`, so `f(y_−) < 0 < f(y_+)`; take `y₁ := y_−`, `y₂ := y_+`. ∎

### Lemma 5 (continuity in the parameters) — `continuous_evalAt_left`
For `M ∈ A_d[Y]` and `c ∈ ℝ`, the function `ℝ^d → ℝ`, `τ ↦ M(τ; c)`, is continuous.

*Proof.* `M(τ; c) = ∑_{k ≤ deg M} ev_τ(m_k) · c^k`, `m_k ∈ A_d` the coefficients of `M`
(`Polynomial.eval₂_eq_sum_range`), a finite sum; and `τ ↦ ev_τ(m) = (m̄)(τ)`, where `m̄ ∈ ℝ[T]` is
`m` with coefficients mapped to `ℝ` (`MvPolynomial.eval₂_eq_eval_map`), is a polynomial function,
hence continuous (`MvPolynomial.continuous_eval`). ∎

### Lemma 6 (persistence of a simple real root) — `exists_root_near`
Let `M ∈ A_d[Y]`, `τ₀ ∈ ℝ^d`, `β₀ ∈ ℝ` with `M(τ₀; β₀) = 0` and `M'(τ₀; β₀) ≠ 0`. Then there is
`δ > 0` such that for every `τ ∈ ℝ^d` with `dist τ τ₀ < δ` there is `β ∈ ℝ` with `M(τ; β) = 0`.

*Proof.* Let `f := ev_{τ₀} M ∈ ℝ[Y]`. By definition `f(β₀) = M(τ₀; β₀) = 0`, and
`f'(β₀) = (ev_{τ₀} M')(β₀) = M'(τ₀; β₀) ≠ 0`, because differentiation commutes with mapping the
coefficients (`Polynomial.derivative_map`). By Lemma 4 there are `y₁, y₂` with
`M(τ₀; y₁) < 0 < M(τ₀; y₂)`. By Lemma 5 the set
`U := {τ | M(τ; y₁) < 0} ∩ {τ | 0 < M(τ; y₂)}` is open; it contains `τ₀`; so it contains the ball
of some radius `δ > 0` about `τ₀`. Let `dist τ τ₀ < δ`. The function
`y ↦ M(τ; y) = (ev_τ M)(y)` is a polynomial function on `ℝ`, hence continuous; it is `≤ 0` at `y₁`
and `≥ 0` at `y₂`; by the intermediate value theorem on the connected space `ℝ`
(`mem_range_of_exists_le_of_exists_ge`) it takes the value `0`. ∎

### Lemma 7 (evaluation through a factorization) — `evalAt_of_map_eq`, `derivative_map_eq`
Let `Fr` be a commutative ring, `κ : A_d → Fr` a ring homomorphism, `M ∈ A_d[Y]`, `b ∈ A_d`,
`ν ∈ Fr[Y]` with `κ(M) = κ(b) · ν` in `Fr[Y]` (`κ` applied to the coefficients; `κ(b)` a constant
polynomial). Let `B` be a commutative `ℚ`-algebra, `s ∈ B^d`, and `θ : Fr → B` a ring
homomorphism with `θ ∘ κ = ev_s`. Then for all `y ∈ B`:

  (a) `M(s; y) = ev_s(b) · (θ ν)(y)`;  (b) `κ(M') = κ(b) · ν'`;  hence
  (c) `M'(s; y) = ev_s(b) · (θ ν')(y)`.

*Proof.* (a) `ev_s M = θ(κ M) = θ(κ(b) · ν) = θ(κ b) · θ(ν) = ev_s(b) · θ(ν)`; evaluate at `y`.
(b) `κ(M') = (κ M)' = (κ(b) · ν)' = κ(b) · ν'` (`Polynomial.derivative_map`,
`Polynomial.derivative_C_mul`). (c) is (a) applied to `(M', b, ν')`, whose hypothesis is (b). ∎

### Lemma 8 (the polynomial of a finitely generated field) — `exists_poly_of_finite`
Let `K` be a field of characteristic `0`, `t = (t₁,…,t_d) ∈ K^d` algebraically independent over
`ℚ`, `F := ℚ(t) ⊆ K` (Lean: `IntermediateField.adjoin ℚ (Set.range t)`), and suppose
`[K : F] < ∞`. Then there are `α ∈ K` and `M ∈ A_d[Y]` such that
1. `M(t; α) = 0`,
2. `M'(t; α) ≠ 0`,
3. for all `τ ∈ ℝ^d` algebraically independent over `ℚ` and all `β ∈ ℝ` with `M(τ; β) = 0`, there
   is a ring homomorphism `K → ℝ`.

*Proof.* `F` has characteristic `0`, so the finite extension `K/F` is separable, and by the
primitive element theorem (`Field.exists_primitive_element`) there is `α ∈ K` with `F(α) = K`
(as intermediate fields: `F⟮α⟯ = ⊤`). `α` is integral over `F` (`IsIntegral.of_finite`). Let
`μ ∈ F[Y]` be its minimal polynomial. `μ(α) = 0` (`minpoly.aeval`); `μ` is irreducible
(`minpoly.irreducible`), hence separable since `F` has characteristic `0`
(`Irreducible.separable`), hence `μ'(α) ≠ 0` (`Polynomial.Separable.aeval_derivative_ne_zero`).

Let `C := ℚ[t] ⊆ K` be the subalgebra generated by the `t_i` (Lean:
`Algebra.adjoin ℚ (Set.range t)`). Since `t` is algebraically independent, `a ↦ a(t)` is an
isomorphism of rings `ε : A_d ≅ C` (Lean: `ht.aevalEquiv`), and `F` is the field of fractions of
`C` (mathlib: the scoped instance
`IsFractionRing (Algebra.adjoin F S) (IntermediateField.adjoin F S)` of the namespace
`IntermediateField.algebraAdjoinAdjoin`); write `ι : C → F` for the inclusion
(`algebraMap C F`). Clearing denominators (`IsLocalization.integerNormalization_spec`, for the
submonoid of the nonzero-divisors of `C`): there are `N ∈ C[Y]` and `c ∈ C`, `c ≠ 0`, with
`ι(N) = c • μ = ι(c) · μ` in `F[Y]`. Put

  `κ := ι ∘ ε : A_d → F`,  `σ := ε⁻¹ : C → A_d`,  `M := σ(N) ∈ A_d[Y]`,  `b := σ(c) ∈ A_d`.

Then `κ ∘ σ = ι`, so `κ(M) = ι(N) = ι(c) μ = κ(b) μ`: the hypothesis of Lemma 7 holds with
`Fr := F`, `ν := μ`. Also `b ≠ 0`, because `σ` is injective and `c ≠ 0`.

*(1) and (2).* Take `B := K`, `s := t`, `θ :=` the inclusion `F → K` (`algebraMap F K`). Then
`θ(κ(a)) = ε(a) = a(t) = ev_t(a)` (`AlgebraicIndependent.algebraMap_aevalEquiv`). By Lemma 7(a),
`M(t; α) = ev_t(b) · μ(α) = 0`. By Lemma 7(c), `M'(t; α) = ev_t(b) · μ'(α)`, a product of two
nonzero elements of the field `K`: `ev_t(b) ≠ 0` since `ev_t` is injective (`t` algebraically
independent: `algebraicIndependent_iff_injective_aeval`) and `b ≠ 0`; `μ'(α) ≠ 0` by separability.

*(3).* Let `τ ∈ ℝ^d` be algebraically independent and `M(τ; β) = 0`. Then `ev_τ : A_d → ℝ` is
injective, so `g := ev_τ ∘ σ : C → ℝ` is an injective ring homomorphism of the domain `C` into
the field `ℝ`; it extends to the field of fractions: `λ := IsFractionRing.lift g : F → ℝ` with
`λ ∘ ι = g` (`IsFractionRing.lift_algebraMap`). Hence
`λ(κ(a)) = λ(ι(ε a)) = g(ε(a)) = ev_τ(σ(ε(a))) = ev_τ(a)`. Lemma 7(a) with `B := ℝ`, `s := τ`,
`θ := λ`: `0 = M(τ; β) = ev_τ(b) · (λ μ)(β)`. As `ev_τ(b) ≠ 0` (injectivity, `b ≠ 0`),
`(λ μ)(β) = 0`: `β` is a root in `ℝ` of the image of `μ` under `λ`. By the universal property of
`F[Y]/(μ)` there is a ring homomorphism `F[Y]/(μ) → ℝ` extending `λ` with `Y ↦ β`
(`AdjoinRoot.lift λ β _`). Composing with the isomorphisms
`K ≅ (⊤ : IntermediateField F K) = F⟮α⟯ ≅ F[Y]/(μ)` (`IntermediateField.topEquiv`,
`IntermediateField.equivOfEq`, `IntermediateField.adjoinRootEquivAdjoin`, each read as a ring
homomorphism in the appropriate direction) gives a ring homomorphism `K → ℝ`. ∎

(Remark: the homomorphism maps `t_i ↦ τ_i` and `α ↦ β`, but this is not needed and not proved.)

### Lemma 9 (generators of a generated subfield) — `subfield_closure_coe_preimage`
Let `L` be a field, `T ⊆ L`, `K₀ := Subfield.closure T`. Then, in the field `K₀`, the subfield
generated by the preimage of `T` under the inclusion `K₀ → L` is all of `K₀`.

*Proof.* Let `x ∈ K₀`. Induction on the construction of `x` as an element of
`Subfield.closure T` (`Subfield.closure_induction`, with the dependent motive
`fun x hx => (⟨x, hx⟩ : K₀) ∈ Subfield.closure (coe ⁻¹' T)`): a generator lies in the preimage of
`T`; `1`, sums, negatives, inverses and products of elements of a subfield lie in it. ∎

### Lemma 10 (a transcendence basis inside the generators) — `exists_transcendence_data`
Let `K` be a field of characteristic `0` generated as a field by a finite set `s`
(`Subfield.closure s = ⊤`). Then there are `d ∈ ℕ` and `t ∈ K^d`, algebraically independent over
`ℚ`, such that `K` is finite-dimensional over `F := ℚ(t)`.

*Proof.*
(i) `ℚ(s) = K` as an intermediate field of `K/ℚ`: the underlying subfield of the intermediate
field `ℚ(s)` is the subfield generated by `ℚ ∪ s` (`IntermediateField.adjoin_toSubfield`), which
contains the subfield generated by `s`, i.e. everything.
(ii) `K` is algebraic over the subring `ℚ[s]` (`Algebra.adjoin ℚ s`): every `x ∈ K = ℚ(s)` is a
quotient `x = r / q` with `r, q ∈ ℚ[s]` (`IntermediateField.mem_adjoin_iff_div`); `r` and `q` are
algebraic over `ℚ[s]` (they are images of elements of it: `isAlgebraic_algebraMap`), hence so are
`q⁻¹` (`IsAlgebraic.inv_iff`) and `r · q⁻¹` (`IsAlgebraic.mul`; `ℚ[s]` is a domain). (This is the
instance hypothesis of the next step.)
(iii) By `exists_isTranscendenceBasis_subset` there is `u ⊆ s` such that the family
`((↑) : u → K)` is a transcendence basis of `K` over `ℚ`. `u` is finite (a subset of `s`). Let
`d := #u`, `e : u ≃ Fin d`, `t i := (e⁻¹ i : K)`. `t` is algebraically independent
(`algebraicIndependent_equiv`), and `Set.range t = u`.
(iv) `K` is algebraic over `F = ℚ(u)` (`IsTranscendenceBasis.isAlgebraic_field`, with
`Set.range ((↑) : u → K) = u`, `Subtype.range_coe`).
(v) `F(s) = K` as an intermediate field of `K/F`
(`IntermediateField.adjoin_eq_top_of_adjoin_eq_top` from (i)). `s` is finite and each of its
elements is integral over `F` (algebraic over a field, by (iv)), so `F(s)` is finite-dimensional
over `F` (`IntermediateField.finiteDimensional_adjoin`); transport along the linear equivalence
`(⊤ : IntermediateField F K) ≃ K` (`IntermediateField.topEquiv`, `Module.Finite.equiv`). ∎

Degenerate cases: `s = ∅` (then `K = ℚ`, `u = ∅`, `d = 0`); `u = s` (then `K = F`, of degree `1`).
Both are covered by the general argument.

### Lemma 11 (signs of rational numbers) — `sign_algebraMap_rat`
In an ordered field `L`, `sign (algebraMap ℚ L a) = sign a` for every `a ∈ ℚ`.

*Proof.* `algebraMap ℚ L = Rat.cast` (`eq_ratCast`) is strictly monotone (`Rat.cast_lt`), and a
strictly monotone zero-preserving map preserves signs (`StrictMono.sign_comp`). ∎

### Lemma 12 (E): a finitely generated "real" field maps to `ℝ` — `nonempty_ringHom_real`
Let `K` be a field of characteristic `0` generated as a field by a finite set `s`, and suppose
there is a ring homomorphism `j : K → L` into a real closed ordered field `L`. Then there is a
ring homomorphism `K → ℝ`.

*Proof.* Lemma 10 gives `d` and `t`. Lemma 8 gives `α`, `M` with (1), (2), (3). Apply `j`
(Lemma 1): in `L`

  `M(j ∘ t; j α) = j(M(t; α)) = 0`,  `M'(j ∘ t; j α) = j(M'(t; α)) ≠ 0`

(`j` is injective, being a ring homomorphism between fields: `map_ne_zero`). Let
`x := (j α, j t₁, …, j t_d) ∈ L^{d+1}` (`Fin.cons (j α) (j ∘ t)`), and `Q₀ := Φ⁻¹ M`,
`Q₁ := Φ⁻¹ M'` in `ℚ[X₀,…,X_d]`. By Lemma 2 the two displayed values are `Q₀(x)` and `Q₁(x)`. The
coefficient maps `ℚ → L` and `ℚ → ℝ` give every rational number the same sign (Lemma 11, twice),
and `L` and `ℝ` are real closed (`instance : IsRealClosed ℝ`), so
`Hilbert17Transfer.exists_matching_signs_eval₂` (with `A := ℚ`, `n := d + 1`, `m := 2`,
`Q := ![Q₀, Q₁]`) gives `y ∈ ℝ^{d+1}` with `sign Q₀(y) = sign Q₀(x) = sign 0 = 0` and
`sign Q₁(y) = sign Q₁(x) ≠ 0`. Write `y = (β₀, τ₀)` with `β₀ := y 0`, `τ₀ := Fin.tail y`
(`Fin.cons_self_tail`). By Lemma 2 again, and `sign v = 0 ↔ v = 0` (`sign_eq_zero_iff`):
`M(τ₀; β₀) = 0` and `M'(τ₀; β₀) ≠ 0`.
Lemma 6 gives `δ > 0`; Lemma 3 gives an algebraically independent `τ` with `dist τ τ₀ < δ`;
Lemma 6 gives `β` with `M(τ; β) = 0`; (3) of Lemma 8 gives a ring homomorphism `K → ℝ`. ∎

### Lemma 13 (a non-sum-of-squares is negative under a real embedding) — `exists_ringHom_real_neg`
Let `K` be a semireal field (`-1` is not a sum of squares; in particular `K` has characteristic
`0`) generated as a field by a finite set `s`, and let `a ∈ K` not be a sum of squares in `K`.
Then there is a ring homomorphism `ψ : K → ℝ` with `ψ(a) < 0`.

*Proof.* By `Hilbert17.RingPreordering.isSumSq_iff_nonneg_all_orders` (contrapositive of `←`)
there is a linear order `o` on `K` making it a strict ordered ring with `¬ (0 ≤_o a)`, i.e.
`a <_o 0`. By `TauCeti.RealClosure.exists_realClosure` there are a real closed ordered field `L`
and a strictly monotone ring homomorphism `j : (K, o) → L`. So `j(a) < j(0) = 0`, `-j(a) ≥ 0`, and
since `L` is real closed (`IsRealClosed.nonneg_iff_isSquare`) there is `w ∈ L` with
`-j(a) = w · w`. `w ≠ 0`: otherwise `j(a) = 0`, contradicting `j(a) < 0`.

Let `T := j(s) ∪ {w} ⊆ L` (finite) and `K₀ := Subfield.closure T`.
* `j(K) ⊆ K₀`: `K = Subfield.closure s`, and `Subfield.closure s ≤ K₀.comap j` because
  `j(s) ⊆ T ⊆ K₀` (`Subfield.closure_le`). Let `j₀ : K → K₀` be `j` with restricted codomain
  (`RingHom.codRestrict`).
* `K₀` is a field of characteristic `0` (a subfield of the ordered field `L`), generated by the
  set `coe ⁻¹' T` (Lemma 9), which is finite (preimage of a finite set under the injective
  inclusion), and the inclusion `K₀ → L` is a ring homomorphism into a real closed field.

Lemma 12 gives a ring homomorphism `φ : K₀ → ℝ`. Put `ψ := φ ∘ j₀`. In `K₀`, with
`w₀ := ⟨w, _⟩ ∈ K₀`: `j₀(a) = -(w₀ · w₀)` (its image in `L` is `j(a) = -(w·w)`). `φ(w₀) ≠ 0`
(`φ` is injective and `w₀ ≠ 0`). Hence `ψ(a) = -(φ(w₀) · φ(w₀)) < 0`. ∎

### Lemma 14 (sums of squares in the field `R` are `SOSIn R`) — `sosIn_of_isSumSq_subfield`
Let `R` be a subfield of `ℝ` and `x` an element of the field `↥R` that is a sum of squares in
`↥R` (`IsSumSq x`). Then `SOSIn R (x : ℝ)`.

*Proof.* Induction on `IsSumSq` (constructors `zero` and `sq_add a s : IsSumSq s →
IsSumSq (a * a + s)`): `0` is `SOSIn.zero`; `a·a + s` with `a ∈ R` is `(a:ℝ)² + (s:ℝ)`, which is
`SOSIn.cons a.2 ih`. ∎

### Theorem 15 — `theorem43For_closure`
For every finite `S ⊆ ℝ`, `Theorem43For (Subfield.closure S)`.

*Proof.* Let `R := Subfield.closure S` and let `g` satisfy `TotNonnegOver R R g`: `g ∈ R` and
(§ 2.1) `0 ≤ ψ(g)` for every ring homomorphism `ψ : R → ℝ`.
*Case 1: `g` is a sum of squares in the field `↥R`.* Then `SOSIn R g` (Lemma 14), and
`g = g / 1` with `SOSIn R 1` (`sosIn_one`), `1 ≠ 0`: this is `QSOS R g`.
*Case 2: `g` is not a sum of squares in `↥R`.* The field `↥R` is an ordered field (a subfield of
`ℝ`), hence semireal (mathlib instance), and it is generated by the finite set `coe ⁻¹' S`
(Lemma 9; finite as the preimage of a finite set under an injective map). By Lemma 13 there is
`ψ : R → ℝ` with `ψ(g) < 0`, contradicting `0 ≤ ψ(g)`. So Case 2 does not occur. ∎

Degenerate cases need no separate treatment: `g = 0` is a sum of squares (the empty sum, Case 1);
`S = ∅` gives `R = ℚ`, `d = 0`, and every lemma holds for `d = 0` (then `A_0 = ℚ[∅]`, the system
has one variable, Lemma 3 is its base case, Lemma 6 holds as stated).

    rw [← map_evalAt]; exact (map_ne_zero j).2 h1
  obtain ⟨y, hy⟩ := Hilbert17Transfer.exists_matching_signs_eval₂ (algebraMap ℚ L) (algebraMap ℚ ℝ)

/-- **In a finitely generated semireal field, an element that is not a sum of squares is
negative under some homomorphism into `ℝ`** (Artin). -/
theorem exists_ringHom_real_neg {K : Type} [Field K] [IsSemireal K] {s : Set K} (hs : s.Finite)
    (hgen : Subfield.closure s = ⊤) {a : K} (ha : ¬ IsSumSq a) :
    ∃ ψ : K →+* ℝ, ψ a < 0 := by
  classical
  obtain ⟨o, hneg⟩ :=
    not_forall.1 (mt (Hilbert17.RingPreordering.isSumSq_iff_nonneg_all_orders a).2 ha)
  obtain ⟨ho, hneg⟩ := Classical.not_imp.1 hneg
  let : LinearOrder K := o
  have : IsStrictOrderedRing K := ho
  obtain ⟨L, fieldL, orderL, orderedL, realClosedL, j, hj, -⟩ :=
    TauCeti.RealClosure.exists_realClosure K
  let : Field L := fieldL
  let : LinearOrder L := orderL
  have : IsStrictOrderedRing L := orderedL
  have : IsRealClosed L := realClosedL
  have ha0 : a < 0 := lt_of_not_ge hneg
  have hja : j a < 0 := by rw [← map_zero j]; exact hj ha0
  obtain ⟨w, hw⟩ := IsRealClosed.nonneg_iff_isSquare.1 (neg_nonneg.2 hja.le)
  have hw0 : w ≠ 0 := by
    rintro rfl
    rw [mul_zero, neg_eq_zero] at hw
    exact hja.ne hw
  -- the field generated by `j '' s` and `w`
  set T : Set L := j '' s ∪ {w} with hT
  have hTfin : T.Finite := (hs.image j).union (Set.finite_singleton w)
  have hjT : ∀ x : K, j x ∈ Subfield.closure T := by
    intro x
    have hx : x ∈ Subfield.closure s := hgen ▸ Subfield.mem_top x
    have hle : Subfield.closure s ≤ (Subfield.closure T).comap j :=
      Subfield.closure_le.2 fun z hz => Subfield.subset_closure (Or.inl ⟨z, hz, rfl⟩)
    exact hle hx
  have hwT : w ∈ Subfield.closure T := Subfield.subset_closure (Or.inr rfl)
  obtain ⟨φ⟩ := nonempty_ringHom_real
    (hTfin.preimage Subtype.coe_injective.injOn) (subfield_closure_coe_preimage T)
    (Subfield.closure T).subtype
  refine ⟨φ.comp (j.codRestrict (Subfield.closure T) hjT), ?_⟩
  have hφw : φ ⟨w, hwT⟩ ≠ 0 := (map_ne_zero φ).2 fun h => hw0 (congrArg Subtype.val h)
  have key : (j.codRestrict (Subfield.closure T) hjT) a = -(⟨w, hwT⟩ * ⟨w, hwT⟩) := by
    apply Subtype.ext
    show j a = -(w * w)
    rw [← hw, neg_neg]
  rw [RingHom.comp_apply, key, map_neg, map_mul]
  have := mul_self_pos.2 hφw
  linarith

/-- A sum of squares in the field `R` is a sum of squares of numbers of `R`. -/
theorem sosIn_of_isSumSq_subfield {R : Subfield ℝ} {x : R} (h : IsSumSq x) :
    SOSIn R (x : ℝ) := by
  induction h with
  | zero => simpa using (SOSIn.zero : SOSIn R 0)
  | @sq_add a s _ ih =>
    have e : ((a * a + s : R) : ℝ) = (a : ℝ) ^ 2 + (s : ℝ) := by push_cast; ring
    rw [e]; exact .cons a.2 ih

/-- **The generalization of Theorem 43 to every domain generated by finitely many real
numbers** (Artin 1927, with rational coefficients): a number of `R = ℚ(S)` that is
nonnegative under every embedding of `R` into `ℝ` is a sum of squares of numbers of `R`. -/
theorem theorem43For_closure (S : Finset ℝ) : Theorem43For (Subfield.closure (S : Set ℝ)) := by
  rintro g ⟨hg, hσ⟩
  by_cases hss : IsSumSq (⟨g, hg⟩ : Subfield.closure (S : Set ℝ))
  · exact ⟨g, 1, sosIn_of_isSumSq_subfield hss, sosIn_one _, one_ne_zero, by simp⟩
  · exfalso
    obtain ⟨ψ, hψ⟩ := exists_ringHom_real_neg
      (S.finite_toSet.preimage Subtype.coe_injective.injOn)
      (subfield_closure_coe_preimage (S : Set ℝ)) hss
    obtain ⟨r, hr, e⟩ := hσ (Complex.ofRealHom.comp ψ) fun y _ => ⟨ψ y, rfl⟩
    have e' : ((ψ ⟨g, hg⟩ : ℝ) : ℂ) = (r : ℂ) := e
    have : ψ ⟨g, hg⟩ = r := Complex.ofReal_injective e'
    linarith

/-- **Theorem 44** (unit `th.44`). -/
theorem theorem44 : Theorem44 := theorem44_of_theorem43For theorem43For_closure
